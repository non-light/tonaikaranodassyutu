# 東京都からの脱出

関東7都県の実際の地図を舞台にした、1〜4人用の協力脱出ゲームです。

- 1台を交代で操作する協力プレイ。途中経過はブラウザに自動保存。
- PeerJSの公開接続サービスでルームを作り、最大4端末で通信。
- 錦糸町から出発し、共有物資を集めて5種類の出口のいずれかに全員集合。
- 探索者、整備士、救護員、登山家の4種類。ソロでは好きな役割を選択。
- 山手線の運転見合わせや雨など、ラウンドごとのイベント。
- 国土地理院の地形タイルをオンライン表示。タイルの取得は関東境界と重なるものに限定。
- 都県境はData of Japanから抽出した関東7都県だけを同梱。東京の離島は対象外。

## 起動

Node.js 22以降で `npm run dev` を実行し、`http://localhost:4173` を開きます。インストールやビルドは不要です。静的ホスティングには `dist/` を配置します。地図タイル、Webフォント、オンラインルームにはインターネットが必要です。地形が読めなくても境界と経路でプレイできます。

`npm test` でゲームのルール・脱出条件・地理範囲を検証します。

## オンライン協力

「オンライン協力」でホストがルームを作成し、他の参加者は同じサイトから7文字のコードで参加します。全員が参加したらホストが開始します。自分の行動順に2回行動し、交代します。

ホストが状態を管理し、参加者の接続とプレイヤーの操作権を対応づけています。ホストは画面を開いておく必要があります。ホストの切断時は各端末に保存された同期状態から、1台でのプレイに切り替わります。途中参加・再接続・ホスト自動移行はありません。PeerJSの公開サービスとWebRTCを使うため、回線の制限によって端末間接続が成立しない場合があります。TURNサーバーは含まれません。

Sites版は初期状態では所有者限定です。他の人がアクセスするには、Sites側で閲覧権限を設定する必要があります。ローカルで遊ぶ場合は同じネットワーク上のこの端末のアドレスからも開けます。

## データとゲーム上の表現

地理院タイル: https://maps.gsi.go.jp/development/ichiran.html

都県境界: https://github.com/dataofjapan/land （国土数値情報を基にしたデータを抽出・簡略化）

鉄道路線・接続は実在の地名を使ったゲーム用の簡略表現です。すべての駅を収録していません。所要時間・封鎖・運休・便・物資は架空です。現実の避難や登山計画には使えません。

## 拡張アイディア

1. 山手線30駅を巡る回収ミッション。先に一周するか、早く外側へ出るか。
2. 荒川・多摩川・江戸川の橋の開閉と、自転車の共同調達。
3. 羽田・成田の出発時刻と、空港ごとに異なる乗員救出ミッション。
4. 東東京から奥多摩への長い徒歩縦走。夜営・天候・荷物の分担。
5. 東京湾を渡る船の修理と、燃料を運ぶ2チームの合流。
6. 群馬・栃木・茨城の無線局を再起動する複数目標モード。
7. プレイヤーごとに一部しか見えない地図と、チャットでの情報共有。
8. 毎日同じ条件で遊ぶシード制チャレンジと脱出記録。
