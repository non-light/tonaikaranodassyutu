# 東京都からの脱出

ある朝、東京都が独立国家「東京国」を宣言。通勤・通学・観光に来ていた埼玉・千葉・神奈川の住民たちが、故郷への帰国を目指す、1〜4人用の協力脱出ゲームです。

- 1台を交代で操作する協力プレイ。途中経過はブラウザに自動保存。
- PeerJSの公開接続サービスでルームを作り、最大4端末で通信。
- 錦糸町から出発し、共有物資を集めて5種類の出口のいずれかに全員集合。
- 探索者、整備士、救護員、登山家の4種類。ソロでは好きな役割を選択。
- 山手線の運転見合わせや雨など、ラウンドごとのイベント。
- 6つの立場（通勤客・観光客・配達員・学生・取材班・ライブ帰り）を抽選。直前の物語は連続しません。
- 出身県・市、追跡者、必須任務の場所が毎回変わり、ホストが決めた同じ設定を全端末で共有。
- 証明書回収・救出・県外への通信という3つの必須任務。複数人の救出には2人の合流が必要。
- 追跡隊は目撃地点へ地図上を移動。潜伏・徒歩・通信機を使った陽動で追跡をかわす。
- 追跡者ごとに検知や移動、出口の警備が異なる。3度の拘束で失敗。
- 旧バージョンの保存データは旧ルールで継続可能。新しい遠征から新設定を適用。
- 国土地理院の地形タイルをオンライン表示。タイルの取得は関東境界と重なるものに限定。
- 都県境はData of Japanから抽出した関東7都県だけを同梱。東京の離島は対象外。

## 起動

Node.js 22以降で `npm run dev` を実行し、`http://localhost:4173` を開きます。インストールやビルドは不要です。静的ホスティングには `dist/` を配置します。地図タイル、Webフォント、オンラインルームにはインターネットが必要です。地形が読めなくても境界と経路でプレイできます。

`npm test` でゲームのルール・脱出条件・地理範囲を検証します。

## オンライン協力

「オンライン協力」でホストがルームを作成し、他の参加者は同じサイトから7文字のコードで参加します。全員が参加したらホストが開始します。自分の行動順に2回行動し、交代します。

ホストが状態を管理し、参加者の接続とプレイヤーの操作権を対応づけています。ホストは画面を開いておく必要があります。切断の自動検知に時間がかかる場合は、待機表示の引き継ぎボタンを押すと、そのプレイヤーをホストが操作できます。ホストの切断時は各端末に保存された同期状態から、1台でのプレイに切り替わります。途中参加・再接続・ホスト自動移行はありません。PeerJSの公開サービスとWebRTCを使うため、回線の制限によって端末間接続が成立しない場合があります。TURNサーバーは含まれません。

Sites版は初期状態では所有者限定です。他の人がアクセスするには、Sites側で閲覧権限を設定する必要があります。ローカルで遊ぶ場合は同じネットワーク上のこの端末のアドレスからも開けます。

## データとゲーム上の表現

地理院タイル: https://maps.gsi.go.jp/development/ichiran.html

都県境界: https://github.com/dataofjapan/land （国土数値情報を基にしたデータを抽出・簡略化）

鉄道路線・接続は実在の地名を使ったゲーム用の簡略表現です。すべての駅を収録していません。所要時間・封鎖・運休・便・物資は架空です。現実の避難や登山計画には使えません。

## 帰国任務と追跡

Aは指定地点で身分証や証明書を回収（1行動、乗車券+3）。Bは指定地点で仲間・都民協力者を救出（1行動、食料2消費、食料4・山装備1を獲得）。複数人プレイでは同じ地点に2人が必要、ソロは1人で実行できます。A・Bを達成後、Cを抽選された2か所のどちらかで実行（1行動、通信機1消費、乗車券+2、追跡度−3）。

3任務の達成に加え、全員集合・物資・追跡度6以下が共通の脱出条件。一部の追跡者は4以下を要求します。出口に追跡隊がいる場合は陽動が必要です。

通常は鉄道・探索で追跡度+1、任務で+2。追跡度3以上で毎ラウンド1区間、7以上で2区間進みます。徒歩は新しい目撃情報を残しません。潜伏は1行動で追跡度−3、次ラウンドまでその人を発見から守ります。移動・探索・任務をすると潜伏は解除。陽動は1行動・通信機1で追跡度−4、追跡隊を1ラウンド停止。

発見されると錦糸町へ送還、体力−2、食料2没収、次の手番は1行動になります。同時に複数人が見つかった場合は1回の拘束として数えます。3度の拘束で失敗します。

都民全員が敵という設定ではなく、独立を支持する一部の自警団や国家機関と、帰郷を手助けする都民の協力者が登場します。

## 拡張アイディア

1. 山手線30駅を巡る回収ミッション。先に一周するか、早く外側へ出るか。
2. 荒川・多摩川・江戸川の橋の開閉と、自転車の共同調達。
3. 羽田・成田の出発時刻と、空港ごとに異なる乗員救出ミッション。
4. 東東京から奥多摩への長い徒歩縦走。夜営・天候・荷物の分担。
5. 東京湾を渡る船の修理と、燃料を運ぶ2チームの合流。
6. 群馬・栃木・茨城の無線局を再起動する複数目標モード。
7. プレイヤーごとに一部しか見えない地図と、チャットでの情報共有。
8. 毎日同じ条件で遊ぶシード制チャレンジと脱出記録。
